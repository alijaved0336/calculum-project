# Changelog

### 2026-10-12

- `feature` `ap` — The Working Capital Achievement tab only showed charts and the top suppliers, so users could not see how every supplier of the active file did against the comparison file. It now has Overview and List sub-tabs: List shows every active-file supplier with its status and, grouped by Current File / Comparison File, payment terms, spend volume, target terms and cash flow opportunity, with filters, paging, a totals row that follows the filters, and an Excel export logged in the audit log (AB#20545).
- `bugfix` `ap` — Enabling receivables (MODULE_AR) on a company did not show the AP sidebar's AP/AR switch to its users, because it also required a super-admin or sales role; the switch now shows for every user whose active company has MODULE_AR.

### 2026-10-11

- `bugfix` `ar` — The Customer Card's Company Credit Rating showed the country's band description ("Very Strong Credit Rating" for a CCC+ buyer in an AA+ country); it now shows the level of the company's own row in the credit score reference table, the same row its grade comes from (a customized rating included), or "—" when there is none.

### 2026-10-08

- `bugfix` `ar` — The Customer Card's Contractual tooltip framed the terms around cash discounts; it now uses the agreed wording, the terms as per the supplier–buyer agreement.
- `bugfix` `ar` — The Customer Card's Sales Materiality tooltip described materiality against the supplier's portfolio; it now uses the agreed wording, against the supplier's overall annual revenue.
- `feature` `ar` — Compact Customer Card figures ($16.3k) hid the real amount; every value on the Opportunity and Ratings & Metrics tabs now has a hover tooltip, money ones showing the full figure (separators, sign, one decimal), and Company Credit Rating's description shows the credit-score band like Country Rating does.
- `bugfix` `ar` — The Customer Card's Ratings & Metrics stat boxes spilled past their card padding and some values sat off-center, and several info tooltips didn't explain what each card shows; layout is fixed and the Company Credit Rating, Buyer Financial Metrics, Buyer Financing Rate and new Country Rating tooltips use the agreed wording.
- `feature` `ar` — Text values (e.g. Main Industry) in the Customer Card's strategy-detail cards and the Parent Organization name overflowed at the numeric figures' size; they now use a smaller font so they read without crowding the card.
- `bugfix` `ar` — A Customer Card opened from a grid's entity cell (or a direct URL) had no sales lines, so its Opportunity tab never showed the Buyer / Sale Line tabs; the view now takes them from the corporate tree's requested node when the caller seeded none.
